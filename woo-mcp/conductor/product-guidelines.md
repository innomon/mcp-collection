# Product Guidelines

## Core Principles

### Security and Robust Authentication
The server must prioritize robust security measures, particularly emphasizing JWT/RSA asymmetric authentication. All interactions between AI Agents and the WooCommerce store will be secured, ensuring data integrity and confidentiality. This includes secure token verification, protection against unauthorized access, and adherence to best practices for API security.

### Ease of Integration for AI Agents
The MCP server is designed to be easily integratable by various AI agents. This involves providing clear API specifications, comprehensive documentation, and a straightforward integration process to minimize development effort for agent developers. The goal is to enable AI agents to seamlessly connect and interact with WooCommerce functionalities.
