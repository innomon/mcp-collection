# Core Mail Server - Track Spec

## Overview
Focus on implementing the basic tools for email operations: `list_folders`, `list_messages`, `get_message`, and `send_email`.

## Milestones
1.  **Project Initialization**: Scaffolding and `go.mod` setup.
2.  **Configuration & Auth**: Config parsing and SASL/OAuth integration.
3.  **IMAP Implementation**: Folder listing and message fetching.
4.  **SMTP Implementation**: Basic email sending.
5.  **MCP Tool Integration**: Registering tools with the MCP SDK.
6.  **Verification**: Manual testing and basic unit tests.
